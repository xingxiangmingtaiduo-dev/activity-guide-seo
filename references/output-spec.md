# 交付语言、标题与补图格式

默认交付英语 en、印尼语 id、葡萄牙语 pt、西班牙语 es、泰语 th、繁体中文 zh-TW、越南语 vi。每种语言各一份 Markdown 和 DOCX，共 14 个文件。简体中文仅作内部基稿，用户另有要求时才交付。

以上为生成前确认中展示的默认值。用户指定其他语言或文件格式时，以已确认要求为准；所有实际输出版本仍须完整本地化。

## Discord 社群邀请

每个语言版本的文章底部都要加入本地化邀请模块。葡萄牙语（pt）和西班牙语（es）使用 `https://discord.gg/FhSaQfq6rJ`；英语（en）、印尼语（id）、泰语（th）、繁体中文（zh-TW）和越南语（vi）使用 `https://discord.gg/Agkk96vcfA`。邀请文案、链接标签和 CTA 必须翻译成目标语言，Markdown 与 DOCX 使用相同内容和链接。

默认文案含义：欢迎读者加入 Discord，获取更多福利、游戏攻略和最新资讯；社群内会更新实用内容和专属福利。不得虚构社群规模、福利数量、官方身份或保证。

文件名使用 `<slug>-<语言代码>.md` 和 `<slug>-<语言代码>.docx`。ASCII 文件名不能代替文章内部标题的翻译。

## 标题检查

每份文件的文章标题、SEO Title、H1、小标题、摘要、CTA、图片说明和图注都必须使用目标语言。SEO 字段名可保留技术标签，字段内容必须本地化。游戏和产品官方名称可以保留原名。

生成前维护内部标题清单：语言代码、文章标题、SEO Title、H1。保存后重新读取 Markdown 和 DOCX，检查实际标题，不能只检查正文。DOCX 首段标题、页眉（如有）和文档标题属性也必须本地化。

## 图片占位说明

图片未能下载或无法正常插入时，在相关段落后添加可见提示块。下面的中文只说明格式，交付时需把所有标签和内容翻译成目标语言：

> **待添加图片 1**
>
> **建议画面：** 添加本次活动的奖励展示图，优先选择来源网页中与本段对应的图片。
>
> **用途：** 帮助读者了解本段介绍的奖励。
>
> **来源：** 参考文章的已确认链接。
>
> **图片链接：** 有已确认的图片链接就填写；否则写“尚未获取，可从来源网页选择”。
>
> **建议图注：** 本次活动的奖励一览。

依据文章内容填写具体画面和用途，不能把奖励示例复制到所有文章。未看过图片时使用“建议添加……”而非描述不存在的细节。Markdown 使用引用块，DOCX 使用可见提示段落。编号和位置在两种格式中一致。补图提示不计入正文长度。

下载成功时，用真实图片和本地化图注替换提示块。检查图片文件、Markdown 路径和 DOCX 嵌入效果之后才能报告“已插入”。
